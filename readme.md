# 🏴‍☠️ PortMate

### A lightweight Linux port and process manager built with C++ and Qt

PortMate is an open source, native Linux desktop application designed to make inspecting network ports and managing associated processes simple.

Whether you're running local development servers, APIs, databases or multiple background services, PortMate aims to provide a straightforward way to discover which ports are in use, identify the processes behind them and terminate processes when necessary.

**The goal is simple:** Open PortMate, find your port, see what's using it and take action.

> 🚧 **Development Status:** Early development. Core port discovery and process management functionality are currently being developed.

### Implemented

* Initial Qt desktop application structure.
* C++ service and model architecture.
* Linux RAM statistics retrieval through `/proc/meminfo`, including total, available and estimated used memory.
